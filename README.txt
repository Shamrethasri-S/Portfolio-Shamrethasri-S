SHAMRETHASRI PORTFOLIO WEBSITE

Files:
- index.html: main website page
- style.css: website styling, including the circular hero portrait fix
- script.js: interactions and animations
- assets/profile.jpg: hero/profile photo
- assets/about-photo.jpg: About section photo
- assets/avatar.gif: animated project mascot

HOW TO OPEN:
1. Extract this ZIP folder.
2. Keep the assets folder beside index.html.
3. Double-click index.html to open the portfolio in a browser.
4. Internet access is needed for the Google Fonts used by the page.

The hero section now has one profile image element (no duplicate ID) and a circular frame beside the “Ideas into digital reality.” heading.
